# 关键: paddleocr 与 torch 常常装不进同一个环境 —— 两者对 numpy / opencv /
# Python 版本的要求互相冲突 (例: paddleocr 2.7 认 py3.8+numpy1.24+opencv4.6,
# 而 ultralytics 8.x 已在 py3.10+numpy2.2 上验证)。因此 tl_vision 把 OCR 拆成
# 独立节点, 两个节点可以各跑各的 conda 环境, 只通过 /tl_vision/plate_crop
# 话题通信。详见 README 「车牌 OCR」一节。
#
# 国内源装 paddlepaddle 会快很多:
#   pip install -i https://paddlepaddle.org.cn/packages/stable/ paddlepaddle
#   pip install paddleocr
