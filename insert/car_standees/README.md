# 车牌汽车立牌

三个可单独插入的静态立牌：

- `car_standee_plate_1.sdf`：车牌一
- `car_standee_plate_2.sdf`：车牌二
- `car_standee_plate_3.sdf`：车牌三

## 随机车牌库存

`plate_inventory/` 是启动场景时抽取车牌的库存目录。将车牌图片（PNG、JPG 或 JPEG）直接放在此目录中即可；每次真正启动或重启 Gazebo 时，会无重复随机抽取三张，分别用于场景里的三个汽车立牌。库存至少需要三张图片。

`scripts/start_sim.sh` 会在启动新 Gazebo 实例前生成临时材质映射，不会改写下方的三个立牌 SDF，也不会改动 world 中立牌的位置。抽中的文件名会打印在启动终端。

背景板尺寸严格为宽 `0.345m`、厚 `0.005m`、高 `0.25m`。每块车牌贴在汽车图片正面的原车牌槽位置，尺寸严格为宽 `0.095m`、高 `0.03m`；背面不贴图。

插入时把模型的 `z` 设为地图地面顶面高度 `0.083333333m`，例如：`<pose>x y 0.083333333 0 0 yaw</pose>`。
