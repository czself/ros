|---|---|

| `04_综合展示视频` | 录制脚本与待补画面清单；含全队讲解的正式 MP4 待录制。 |
| `05_运行证据` | 20次完整任务的原始审计汇总、CSV、图表和展示图片，含全部失败轮次。 |
| `06_规则与参考` | 官方赛题 PDF 与本地任务要求原件。 |

当前20次任务的原独立完整验收是16/20，15个不同车牌号码里整牌识别58/60，人物报告每次都是18人（社区16、外来2）。第7点有1次重新补位；AMCL回位合格与实际车身起终点偏差不同，不能宣称物理回到原姿态已经验证通过。详见 `05_运行证据/REPORT.md`。

评委复现请先解压 `01_工程代码/智算三行队-智慧社区复赛工程代码.zip`，按压缩包根目录 `README.md` 安装系统与 Python 依赖、编译四个 catkin 包，再执行 `./native_demo.sh demo_001` 和 `./native_audit.sh demo_001`。源码包自带模型，系统依赖与 bag 需要在评委电脑上生成；当前Git源码历史不替代解压后的实际复现测试。

正式提交仍要求四个文件：`智算三行队-智慧社区复赛技术方案.pdf`、`智算三行队-智慧社区复赛工程代码.zip`、`智算三行队-智慧社区复赛答辩展示.pdf`、`智算三行队-智慧社区复赛综合展示视频.mp4`。前述 PDF 与 MP4 未完成时，不能把此目录称为完整提交。
