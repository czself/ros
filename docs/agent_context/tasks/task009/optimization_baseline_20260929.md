## 执行顺序（用户已同意“先梳理，然后开始”）

1. 导航：先核对并合并重复稳定等待，再分析短距离目标的“行驶朝向—拍照朝向”切换及末端慢行；每次只改一项。
2. 人物：复用现有拍照帧组，按人物区域质量和完整性评估选帧；比较同一原图/裁剪图的真实模型结果，再决定是否准备仿真样本微调。
3. 记录真实置信度分布、分类准确率和漏检，不能把阈值调整或显示分数调整当作模型提升。

- 比较完整耗时、剔除信号等待后的耗时、原地对齐时间、停顿和方向修正次数；不能把信号相位差异当作速度提升。

- 新版本出现安全接触、识别下降、回位不达标或没有可解释改善，先回退该项。
