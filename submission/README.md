# 智算三行队复赛材料整理

运行 `python3 scripts/organize_submission.py --team 智算三行队`，在 `/home/sz/game/复赛提交材料/智算三行队` 生成独立的整理副本。原工作区、历史记录与运行数据保持在原位置。

| 目录 | 内容 | 当前状态 |
|---|---|---|
| 01_工程代码 | 正式命名的 ZIP、解压后的 ROS src 工作空间、编译运行 README | 可整理与检查；新机器完整运行尚待复现 |
| 02_技术方案 | 与当前代码对应的技术方案 Markdown 草稿 | 需补充队员、确定实车硬件和排版成正式 PDF |
| 03_答辩展示 | 幻灯片提纲、关键数据与证据索引 | 需制作幻灯片并导出 PDF |
| 04_综合展示视频 | 录制脚本与现有视频素材 | 缺少符合规则的完整演示、队员讲解与答辩 MP4 |
| 05_运行证据 | 导航旧版 3/3、新人物版 1 次通过的分开记录；图片、报告、播报 | 大型 rosbag 留在原路径 |
| 06_历史与参考 | 旧方案、规则原文、新版 OCR 包、原工作区未提交修改的副本 | 仅作追溯和参考 |

工程只提供当前有效的入口，旧实验脚本另存历史目录。可选 `tl_vision` ROS 包来自用户提供的新压缩包，默认不启动 OCR。`best.pt` 为实际运行的检测模型，SHA-256 应为 `fe502091a4e964371eee3b08ec26029ad653019250d5406e13dc68ce8969a2ad`。

规则要求提交四个正式文件：技术方案 PDF、工程 ZIP（小于 150 MB）、答辩展示 PDF、综合展示 MP4（小于 300 MB，建议 8–12 分钟）。草稿与素材不等同于正式成品。
